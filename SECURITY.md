# Security and Responsible Use

Project Ares is intended exclusively for defensive research and testing on systems you own or are explicitly authorized to assess.

## Boundaries

- Keep vulnerable services and adversary tooling isolated from home, business, and public networks.
- Never use personal/production identities, data, credentials, tenants, or cloud accounts.
- Default to benign simulation and synthetic artifacts; do not deploy self-propagating or destructive payloads.
- Do not expose vulnerable guests directly to the Internet.
- Gate temporary egress and cloud access by allowlist, time limit, logging, budget, and cleanup verification.
- Test emergency stop and restoration before enabling higher-risk scenarios.
- Do not commit secrets, raw evidence, malware, licensed images, or sensitive infrastructure details.

## Vulnerability reports

Do not open a public issue containing an exploitable weakness, credential, or sensitive evidence. Contact the repository owner privately through their published GitHub contact channel.
