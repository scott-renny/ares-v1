# Contributing

Contributions should improve reproducibility, defensive validation, safety, documentation, or testability.

Before proposing a scenario, include its authorized scope, risk tier, ATT&CK mapping, synthetic test data, prerequisites, expected telemetry, abort path, cleanup, reset verification, and tests. Do not submit live credentials, malware, destructive payloads, copyrighted VM images, or instructions targeting third-party systems.

Use focused changes, clear commit messages, and update relevant documentation and validation tests.
