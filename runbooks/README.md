# Runbooks

Planned operator procedures:

- host installation and hardening;
- normal startup/shutdown;
- mission preflight and launch;
- snapshot creation, restore, and reset verification;
- emergency stop and containment;
- failed reset/quarantine;
- backup and recovery;
- AWS lab provisioning and teardown;
- evidence export, redaction, and retention;
- hardware fault and capacity response.

Every runbook should identify owner, prerequisites, exact scope, verification, rollback, and last-tested date.
