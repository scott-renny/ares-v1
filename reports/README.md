# Reporting and Mission History

## Mission history minimum fields

- mission/scenario ID and scenario version;
- operator, approval reference, and correlation ID;
- start/end time and terminal state;
- guest/snapshot versions and relevant configuration hash;
- ordered events, safety interventions, and reset result;
- expected and observed telemetry/detections;
- weighted score, gaps, notes, and evidence references.

## After-action report outline

1. Executive summary
2. Objective, scope, and authorization
3. Environment and scenario version
4. Timeline
5. Detection and response results
6. Safety events and deviations
7. Root causes and gaps
8. Corrective actions, owners, and target dates
9. Reset/teardown verification

Only sanitized examples belong in the public repository. Raw logs, credentials, host details, and sensitive detection logic remain outside version control.
